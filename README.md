# 🧠 Memory AI Project

A **Long-Term Memory AI system** built using **FastAPI** that can extract, store, and recall important user information across long conversations (1000+ turns).  
Designed for hackathons and real-time AI assistants that require **persistent memory**.

---

## 🚀 Features
- 🧠 Long-term memory storage using SQLite
- 🔁 Memory retrieval across multiple turns
- ⚡ Real-time FastAPI backend
- 🌐 Simple web UI (HTML + JavaScript)
- 📑 Swagger API documentation
- 💾 Persistent memory across sessions

---

## 🛠 Tech Stack
- **Python**
- **FastAPI**
- **Uvicorn**
- **Jinja2**
- **SQLite**
- **HTML / CSS / JavaScript**
